# 持仓时长 × PnL 相关性 — 你赚的钱和时间站在同一边吗

**解决一句话问题**：我是在“拿不住盈利”还是在“死扛亏损”，最佳持仓时间到底在哪个区间？

只读复盘 Skill，不下任何单。基于 `positions-history` 计算每笔持仓时长并分桶，量化时长与收益关系，输出可执行的持仓纪律建议。

## 🔁 核心流程

### 第一步：拉取原始数据

```bash
okx --profile <live|demo> account positions-history \
  --instType SWAP \
  --begin <ts> --end <ts> \
  --limit 500 [--archive] --json
```

### 第二步：数据健康校验

- 核验 `oTime/cTime` 可用性
- 去除持仓时长 <=0 的异常记录
- 样本数低于最小阈值则仅输出描述统计

### 第三步：分桶统计

1. 计算 `hold_duration = cTime - oTime`
2. 按边界分桶
3. 每桶统计：笔数、平均 PnL、胜率、平均盈亏比
4. 计算“盈利平均时长”与“亏损平均时长”

### 第四步：相关性洞察

- 拿不住盈利指数 = `亏损平均时长 / 盈利平均时长`
- 识别最优时长区间（胜率与收益综合）
- 方向拆分时分别计算 long/short 的最优桶

洞察规则：
- 亏损时长 > 盈利时长 × 1.5：严重告警
- `<1h` 桶胜率 <40%：建议降低日内高频
- `>7d` 桶胜率高：建议增加长持比例

### 第五步：输出中文 Markdown 报告

输出分桶柱状图、时长指数、方向拆分和具体执行建议。

## 🚧 异常处理

1. `oTime` 缺失：该笔剔除并记录剔除比例。
2. 持仓时长为负：判为数据异常并剔除。
3. 样本过少：输出“观察性结论”，不输出强执行建议。
4. 极端长时持仓：按分位截断并保留原始说明。
5. 429/5xx：重试失败后终止任务并提示重试窗口。

## ❓ Q&A

1. **Q：拿不住盈利指数越高越差吗？**
   **A：是。>1.5 通常表示亏损仓位被拿得比盈利仓位更久，需要立即纠偏。**

2. **Q：样本里 >7d 很少，还能下结论吗？**
   **A：只能给观察性建议，不应据此直接大幅调仓。**

3. **Q：为什么要 long/short 分开看？**
   **A：同一策略在多空方向的最优持仓时长可能完全不同。**

4. **Q：我能自定义分桶吗？**
   **A：可以，支持任意边界组合，建议保持跨期一致便于比较。**

5. **Q：Demo 盘可以用吗？**
   **A：可以，`--profile demo` 下流程一致。**

6. **Q：报告能告诉我“应该持有多久”吗？**
   **A：会给出历史最优区间建议，但仍需结合当前市场状态。**

7. **Q：短线桶胜率低是不是就完全不做短线？**
   **A：先降频并小仓验证，不建议一刀切。重点是先修正执行质量。**

8. **Q：可以导出按方向的详细桶数据吗？**
   **A：支持，完整桶表可写入 Markdown 文件。**
