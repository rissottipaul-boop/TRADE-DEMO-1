# 连胜连亏 & 期望值显微镜 — 看穿序列背后的情绪与边际

**解决一句话问题**：我最近的连胜连亏是随机波动，还是策略正在失效？

只读复盘 Skill，不下任何单。基于 `account positions-history` 按平仓时间排序，提取 W/L 序列、最长 streak、当前 streak、滚动胜率与期望值，给出仓位与节奏建议。

## 🔁 核心流程

### 第一步：拉取原始数据

```bash
okx --profile <live|demo> account positions-history \
  --instType SWAP \
  --begin <开始时间戳ms> --end <结束时间戳ms> \
  --limit 500 \
  [--archive] --json
```

可按参数追加 `--instId` 过滤指定品种。

### 第二步：数据健康校验

```text
样本数 = 有效平仓记录数（realizedPnl 非空）
覆盖率 = 实际样本 / 期望样本
```

- 覆盖率 <80% 或样本 < 最小样本量：拒绝出结论
- 80%-95%：提示“结论置信度中等”
- ≥95%：正常分析

### 第三步：序列分析

1. 按 `cTime` 升序排成交
2. 每笔 `realizedPnl > 0` 记为 `W`，否则记为 `L`
3. 扫描得到：最长连胜、最长连亏、当前 streak
4. 计算每个 streak 段的总盈亏与持续时间
5. 计算滚动胜率曲线（窗口默认 20）

### 第四步：期望值与行为洞察

- 胜率：`win / (win + loss)`
- 盈亏比：`avgWin / avgLoss`
- 期望值：`winRate*avgWin - (1-winRate)*avgLoss`
- 凯利建议：`f* = p - (1-p)/R`，再乘折扣系数
- 连亏后胜率衰减：比较“连亏段后 K 笔胜率”与“总体胜率”

洞察规则：
- 连亏 ≥5：情绪交易预警
- 期望值 <0：策略无正向边际
- 胜率 50%-55% 且盈亏比 <1.5：结构不达标

### 第五步：输出中文 Markdown 报告

输出 streak 时间轴、Top3 序列、滚动胜率曲线、风险建议与仓位动作。

## 🚧 异常处理

1. `positions-history` 空结果：提示“该窗口无平仓数据”。
2. 样本不足：建议扩大时间窗或降低最小样本阈值。
3. 重复记录：按 `tradeId + cTime + instId` 去重。
4. 字段缺失（`realizedPnl/cTime`）：剔除并在报告注明剔除比例。
5. 429/5xx：重试后仍失败则终止并给出补救路径。

## ❓ Q&A

1. **Q：连亏 3 笔就要停吗？**
   **A：不一定。默认预警阈值是 5，低于阈值更多是提醒，不是强制停手。**

2. **Q：期望值为正但最近一直亏，怎么理解？**
   **A：这通常是短期方差。重点看滚动胜率和盈亏比是否同步恶化。**

3. **Q：凯利建议能直接全额执行吗？**
   **A：不建议。默认使用 0.5 折扣凯利，避免估计误差放大回撤。**

4. **Q：可以只分析某个策略标签吗？**
   **A：可通过 `instId` 或时间段筛选近似替代；若有外部标签也可按标签切片。**

5. **Q：Demo 盘和实盘的 streak 逻辑一致吗？**
   **A：一致。差别只在数据来源账户，不在算法。**

6. **Q：报告里的 W/L 时间轴能导出吗？**
   **A：可以，支持随报告一起写入 Markdown 文件，便于回看。**

7. **Q：为什么连胜也会被提醒？**
   **A：过长连胜常伴随过度自信和加杠杆冲动，需提前做风险约束。**

8. **Q：我想把连亏后冷静期从 12h 改成 24h，能改吗？**
   **A：可以，参数支持对话中即时调整并立即生效。**
