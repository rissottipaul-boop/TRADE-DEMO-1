## 用户输入
```
分析我最近的亏损交易
```

## Skill 处理流程

### 1. 解析指令
- 识别分析类型：`亏损交易`分析
- 识别时间范围：默认最近30天（未指定时）
- 识别数据范围：所有产品类型，仅亏损交易
- 识别分析重点：找出亏损原因模式，提出针对性改进

### 3. 亏损原因分类分析

#### 3.1 亏损原因标签系统
建立多维度亏损原因分类：
1. **技术分析错误**（入场/出场时机）
2. **情绪驱动交易**（恐惧/贪婪/冲动）
3. **风险控制失效**（止损不当/仓位过大）
4. **市场环境变化**（突发新闻/市场转向）
5. **策略执行偏差**（未按计划执行）
6. **知识技能不足**（对产品理解不够）
7. **成本费用影响**（高手续费/资金费率）

#### 3.2 逐笔亏损交易分析

**交易#1：BTC看涨期权（最大亏损 -425.80 USDT）**
```
📅 时间：2024-01-10 14:30:00

2. 情绪驱动：FOMO情绪，怕错过突破行情
3. 风险控制：无止损设置（期权无法传统止损）
4. 知识技能：不理解Theta衰减（-0.6%/天）
5. 市场环境：突破后立即回调，IV下降至42%

🏷️ 标签：知识技能不足 + 情绪驱动 + 风险控制失效
```

🔍 亏损原因分析：

3. 市场环境：止损后价格立即反弹至51,200
4. 情绪驱动：害怕亏损扩大，手动提前平仓（原止损49,500）

🏷️ 标签：风险控制失效 + 情绪驱动

### 6. 针对性改进方案

#### 6.1 针对技术分析错误的改进
```
🔧 问题：9笔因技术分析错误亏损
📝 具体表现：入场时机差、忽略关键阻力、未等待确认

✅ 改进措施：
1. 建立入场检查清单（必须满足3/5条件）：
   - RSI在30-65之间
   - 价格在EMA20之上（多头）或之下（空头）
   - 成交量放大（较前日+20%）
   - 有明确支撑/阻力位参考
   - 市场情绪不过热（恐惧贪婪指数<70）

2. 增加确认机制：
   - 日线趋势与入场方向一致
   - 等待1-2根K线确认
   - 分批入场（首批50%，确认后50%）

3. 加强技术学习：
   - 每周研究2个经典形态
   - 记录技术分析预测与实际走势对比
   - 加入交易社群讨论技术分析
```

#### 6.2 针对情绪驱动交易的改进
```
🔧 问题：7笔因情绪驱动亏损
📝 具体表现：FOMO追高、恐惧止损、报复交易

✅ 改进措施：
1. 情绪识别与记录：
   - 交易前填写情绪状态表（1-10分）
   - 识别触发情绪的事件（新闻、盈亏、他人影响）
   - 建立情绪-交易表现关联数据库

2. 情绪管理规则：
   - 情绪分>7时暂停交易30分钟
   - 单笔亏损>2%后强制冷却2小时
   - 连续2笔亏损后当日停止交易

3. 心理训练：
   - 每日冥想5分钟（交易前）
   - 建立交易日志记录情绪变化
   - 学习认知行为疗法基础
```

#### 6.3 针对风险控制失效的改进
```
🔧 问题：5笔因风险控制失效亏损
📝 具体表现：止损过紧、无止损、仓位过大

✅ 改进措施：
1. 科学止损设置：
   - 基于ATR：止损距离 = 2.5×ATR
   - 基于支撑阻力：止损在关键技术位下方
   - 基于资金管理：单笔最大亏损≤账户1.5%

2. 仓位管理系统：
   - 凯利公式调整版：f* = (p×b - q)/b × 0.5（半凯利）
   - 波动率调整：高波动率时减仓50%
   - 分散要求：单品种≤总仓位40%

3. 风险监控：
   - 实时监控保证金率（永续>200%）
   - 设置日亏损限额（账户3%）
   - 设置周亏损限额（账户8%）
```

#### 6.4 针对知识技能不足的改进
```
🔧 问题：3笔因知识不足亏损（主要是期权）
📝 具体表现：不理解IV、Theta、希腊字母

✅ 改进措施：
1. 产品学习计划：
   - 暂停期权实盘交易1个月
   - 完成期权基础课程（10小时）
   - 模拟交易期权策略（备兑开仓、保护性看跌）

2. 知识测试：
   - 交易前通过产品知识小测试
   - 记录不熟悉产品的学习笔记
   - 定期复习关键概念（每月）

3. 渐进式实践：
   - 阶段1：只交易现货和永续
   - 阶段2：加入简单期权策略（模拟）
   - 阶段3：小仓位实践期权（≤账户2%）
```

## 错误处理场景

### 场景1：无亏损交易
```
✅ 恭喜！未发现亏损交易！
分析时间段：最近30天
交易总数：15笔
亏损交易：0笔
胜率：100%

分析建议：
1. 保持当前策略和纪律
2. 考虑小幅增加仓位（如从5%到7%）
3. 记录成功经验，形成固定流程
4. 警惕过度自信风险
```

### 场景2：亏损过于集中
```
⚠️ 亏损高度集中警告！
总亏损：-2,450 USDT（最近30天）
其中单笔亏损：-1,850 USDT（占75.5%）

风险分析：
- 过度集中风险：一次错误可能摧毁多日盈利
- 风控漏洞：缺乏单笔损失限额
- 情绪风险：大亏后可能情绪崩溃

紧急措施：
1. 立即设置单笔损失限额（如账户2%）
2. 分析该大亏原因，制定预防措施
3. 考虑减仓50%直到情绪恢复
```

### 场景3：持续亏损趋势
```
🚨 持续亏损趋势警告！
最近7天：亏损5笔，盈利2笔
最近30天：胜率下降至38%（从52%）
亏损金额趋势：逐周增加

危机分析：
1. 策略可能失效（市场环境变化）
2. 情绪可能恶化（亏损导致更多亏损）
3. 可能需要暂停交易

建议行动：
1. 立即暂停所有实盘交易1-3天
2. 全面复盘最近2周所有交易
3. 考虑回归模拟交易直到稳定盈利
4. 寻求外部帮助（导师、社群）
```
