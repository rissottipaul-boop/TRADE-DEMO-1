# 示例：OCO（止盈止损）订单

## 用户输入
```
为我的 BTC-USDT-SWAP 多头仓位设置止盈 52000，止损 50000
```

- 识别操作：`设置止盈止损`
- 识别标的：`BTC-USDT-SWAP`
- 识别仓位：`多头仓位`
- 识别止盈价：`52000` USDT
- 识别止损价：`50000` USDT
- 识别类型：OCO 订单（One-Cancels-Other）

```bash
okx swap positions --instId BTC-USDT-SWAP
```

### 3. 验证仓位状态
- 持仓方向：`long`（多头）
- 持仓数量：`2` 张
- 持仓均价：`50500.00` USDT
- 当前标记价格：`51000.00` USDT
- 强平价格：`47500.00` USDT

### 4. 计算止盈止损参数
- **止盈触发价**：52,000 USDT（较当前价上涨 1.96%）
- **止损触发价**：50,000 USDT（较当前价下跌 1.96%）
- **仓位数量**：2 张（与持仓一致）
- **订单类型**：市价单（触发后立即成交）

### 5. 风险检查
1. **止盈价合理性**：52,000 > 51,000（当前价）✅
2. **止损价合理性**：50,000 < 51,000（当前价）✅  
3. **价格间距**：52,000 - 50,000 = 2,000（3.9% 区间）✅
4. **强平保护**：50,000 > 47,500（强平价）✅
5. **波动性检查**：2,000 USDT 间隔 ≈ 最近 24h ATR 的 1.5 倍 ✅

```
📊 **风险参数**：
- 盈利风险比：3.0:1（3,000:1,000）
```

### 7. 用户确认
用户输入：`Y`

### 8. 执行命令
```bash
okx algo place \
  --instId BTC-USDT-SWAP \
  --side sell \
  --posSide long \
  --sz 2 \
  --tpTriggerPx 52000 \
  --slTriggerPx 50000 \
  --tpOrdPx -1 \      # -1 表示市价单
  --slOrdPx -1 \      # -1 表示市价单
  --ordType oco \     # OCO 订单类型
  --tgtCcy base_ccy
```

## 关键逻辑说明

1. **OCO 订单原理**：两个条件单绑定，任一触发后另一自动取消
2. **`--tpOrdPx -1` 和 `--slOrdPx -1`**：表示触发后以市价执行
3. **`--ordType oco`**：明确指定 OCO 订单类型
4. **仓位匹配**：确保 OCO 订单数量与持仓数量一致
5. **风险收益比计算**：自动计算并展示 3:1 的比例

## 高级功能：分批止盈

用户可设置多个止盈点：“分两批止盈，52,000 平 1 张，53,000 平 1 张”

### 执行分批止盈 OCO
```bash
# 第一组 OCO：止盈 52,000 / 止损 50,000（1张）
okx algo place \
  --instId BTC-USDT-SWAP \
  --side sell \
  --posSide long \
  --sz 1 \
  --tpTriggerPx 52000 \
  --slTriggerPx 50000 \
  --tpOrdPx -1 \
  --slOrdPx -1 \
  --ordType oco

# 第二组 OCO：止盈 53,000 / 止损 50,000（1张）
okx algo place \
  --instId BTC-USDT-SWAP \
  --side sell \
  --posSide long \
  --sz 1 \
  --tpTriggerPx 53000 \
  --slTriggerPx 50000 \
  --tpOrdPx -1 \
  --slOrdPx -1 \
  --ordType oco
```

## 错误处理场景

### 场景1：无对应仓位
```
❌ 未找到匹配仓位！
查询：BTC-USDT-SWAP 多头仓位
结果：当前无此方向持仓
可能原因：
1. 尚未开仓
2. 持仓方向为 short（空头）
3. 已全部平仓
请先开仓或调整方向。
```

### 场景2：价格设置不合理
```
❌ 价格设置冲突！
止盈价：52,000.00 USDT
止损价：50,000.00 USDT
当前价：51,000.00 USDT

问题：止损价（50,000）< 当前价（51,000）< 止盈价（52,000）✅
但：止损价低于强平价（47,500）时可能直接强平

建议调整：
- 止损价 ≥ 48,000.00（强平价 +2% 安全边际）
- 或使用跟踪止损代替固定止损
```
