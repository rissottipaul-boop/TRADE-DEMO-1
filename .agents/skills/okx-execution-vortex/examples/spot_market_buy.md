# 示例：现货市价买入

## 用户输入
```
执行买入 BTC 1000U
```

## Skill 处理流程

### 1. 解析指令
- 识别操作：`买入`
- 识别标的：`BTC`
- 识别金额：`1000U` (1000 USDT)
- 识别类型：现货市价单（未指定价格）

### 2. 查询行情
```bash
okx market candles --instId BTC-USDT --bar 1m --limit 1
```
返回：
```
{
  "instId": "BTC-USDT",
  "last": "50123.45",
  "askPx": "50123.50",
  "bidPx": "50123.40",
  "ts": "2024-01-15T14:30:00.000Z"
}
```

### 3. 计算数量
```
1000 USDT ÷ 50,123.45 USDT/BTC ≈ 0.01995 BTC
```

### 4. 风险检查
```bash
okx account balance --ccy USDT
```
返回：
```
{
  "totalEq": "15000.00",
  "available": "12000.00",
  "frozen": "3000.00"
}
```
单笔风险计算：1000 ÷ 15000 = 6.67% > 2% (阈值)

**自动调整**：300 USDT (2% of 15000)

调整后数量：300 ÷ 50123.45 ≈ 0.00598 BTC

### 5. 二次确认
输出确认信息：
```
⚠️ **交易确认请求**

市场：BTC-USDT
操作：买入
价格：市价（当前 50,123.45 USDT）
数量：0.00598 BTC（约 300 USDT）
预估手续费：0.15 USDT（0.05% Taker）
账户余额：15,000.00 USDT
单笔风险：2.0%

📊 **风险检查结果**：
✅ 保证金率：不适用（现货）
✅ 余额充足（可用 12,000 USDT）
✅ 系统状态：正常

请确认是否执行？（Y/N）
```

### 6. 用户确认
用户输入：`Y`

### 7. 执行命令
```bash
okx spot place \
  --instId BTC-USDT \
  --side buy \
  --sz 0.00598 \
  --tgtCcy quote_ccy \
  --ordType market
```

## 关键逻辑说明

1. **自动风险调整**：当用户请求金额超过风险阈值时，自动按比例缩减
2. **市价单处理**：使用 `--ordType market` 确保立即成交
3. `--tgtCcy quote_ccy`：以报价货币（USDT）指定数量
4. **完整的确认流程**：展示所有关键信息供用户决策
5. **结果格式化**：人类可读的总结，包含账户变化和风险状态

## 测试命令（--demo 模式）
```bash
okx spot place --instId BTC-USDT --side buy --sz 0.00598 --tgtCcy quote_ccy --ordType market --demo
```
返回模拟结果，不实际下单。

## 错误处理场景

### 场景1：余额不足
```
❌ 余额不足！
请求金额：1000 USDT
可用余额：500 USDT
建议操作：调整金额或充值
```

### 场景2：市场关闭
```
❌ 市场未交易！
BTC-USDT 当前状态：halted（暂停交易）
建议操作：等待市场恢复
```

### 场景3：网络超时
```
⚠️ 网络连接不稳定，正在重试...
第1次重试：失败
第2次重试：成功
（自动重试最多3次）
```
