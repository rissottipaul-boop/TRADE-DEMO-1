# 示例：DCA（定期定额）投资计划

## 用户输入
```
DCA 买入 ETH 每周 500U，持续3个月
```

## Skill 处理流程

### 1. 解析指令
- 识别操作：`DCA 买入`
- 识别标的：`ETH`
- 识别频率：`每周`
- 识别金额：`500U` (500 USDT)
- 识别时长：`3个月`（约13周）
- 识别类型：DCA（Dollar Cost Averaging）定期投资

### 2. 查询市场信息
```bash
okx market candles --instId ETH-USDT --bar 1w --limit 20
okx market indicator --instId ETH-USDT --indicator MA --period 20
```
返回：
```
当前价格：2,800.00 USDT
52周最高：3,500.00 USDT
52周最低：1,800.00 USDT
20周均线：2,750.00 USDT
```

### 3. 计算投资计划
- **每周投资**：500 USDT
- **持续时间**：3个月 ≈ 13 周
- **总投资额**：500 × 13 = 6,500 USDT
- **预计购币量**：6,500 ÷ 2,800 ≈ 2.321 ETH（假设均价不变）
- **执行时间**：每周一 10:00 UTC（可配置）

### 4. 风险与收益分析
1. **风险分散**：
   - 避免一次性买在高点
   - 摊薄成本，降低波动影响
   - 适合长期看好但短期不确定的市场

2. **历史回测**（以过去52周 ETH 数据）：
   - 一次性投资：可能回报 -20% 到 +40%
   - DCA 投资：回报区间 -10% 到 +25%，波动更小
   - 胜率：DCA 在震荡市中胜率 65%，趋势市中胜率 45%

3. **手续费优化**：
   - 每周一次：手续费 0.05% × 13 = 0.65%
   - 每月一次：手续费 0.08% × 3 = 0.24%（更优但平滑效果差）
   - 建议：每周执行，使用 Maker 单（限价单）降低手续费

### 5. 账户检查
```bash
okx account balance --ccy USDT
```
返回：
```
总权益：20,000.00 USDT
可用余额：15,000.00 USDT
```
- 总投资占比：6,500 ÷ 20,000 = 32.5%（较高）
- **自动调整**：建议 ≤25% → 5,000 USDT 总投资
- 调整后每周：5,000 ÷ 13 ≈ 385 USDT

### 6. 二次确认
```
⚠️ **DCA 投资计划确认请求**

标的资产：ETH-USDT
投资策略：定期定额（Dollar Cost Averaging）
当前价格：2,800.00 USDT

📅 **执行计划**：
- 频率：每周一次（每周一 10:00 UTC）
- 每次金额：385.00 USDT（自动从 500 调整）
- 持续周数：13 周
- 开始日期：2024-01-22（下周一）
- 结束日期：2024-04-22
- 总投入：5,000.00 USDT

📊 **投资参数**：
- 下单类型：限价单（当前价 -0.5% 挂单）
- 超时处理：2小时后未成交转市价单
- 失败重试：自动重试最多3次
- 余额检查：每次执行前确认可用余额

💰 **预期结果**（基于历史波动率）：
- 预计购得 ETH：1.75 - 2.10 ETH
- 平均成本：2,380 - 2,860 USDT/ETH
- 预期年化收益率：8-15%（假设 ETH 年涨幅 20%）
- 最大浮亏可能性：-15%（短期市场下跌）
- 成本平滑效果：±12%（相比一次性投资）

🎯 **适用场景**：
✅ 长期看涨但短期方向不明
✅ 避免择时困难
✅ 每月有稳定现金流可投资
✅ 作为资产配置的底仓积累

⚠️ **风险提示**：
1. 牛市踏空风险：上涨行情中成本不断抬高
2. 资金效率：部分资金闲置等待投资
3. 机会成本：可能错过其他投资机会
4. 执行风险：极端行情可能无法按计划成交

请确认是否创建？（Y/N）
```

### 7. 用户确认
用户输入：`Y`

### 8. 执行命令
```bash
okx bot dca create \
  --instId ETH-USDT \
  --investment 385 \
  --frequency weekly \
  --startDate 2024-01-22 \
  --totalCycles 13 \
  --ordType limit \          # 限价单
  --pxOffset -0.005 \        # 当前价 -0.5% 挂单
  --timeout 2h \            # 2小时未成交转市价
  --maxRetries 3 \          # 最多重试3次
  --stopType target \       # 目标型停止
  --stopValue 5000 \        # 总投入达到5000停止
  --notification true       # 启用通知
```

## 关键逻辑说明

1. **`--frequency weekly`**：支持 daily, weekly, biweekly, monthly
2. **`--pxOffset -0.005`**：限价单相对市价的偏移，负值表示更低价挂单
3. **`--timeout 2h`**：挂单超时后自动转市价单，避免错过执行
4. **`--stopType target`** 和 `--stopValue 5000`**：达到总投入目标后自动停止
5. **`--notification true`**：启用邮件/推送通知

## 高级功能：动态 DCA（根据市场调整）

用户可设置智能 DCA：“智能 DCA ETH，市场跌时多买，涨时少买”

```bash
okx bot dca create \
  --instId ETH-USDT \
  --investment 400 \
  --frequency weekly \
  --totalCycles 13 \
  --strategy dynamic \      # 动态策略
  --priceThreshold 0.05 \   # 价格阈值 5%
  --adjustmentFactor 0.5 \  # 调整系数 50%
  --minInvestment 200 \     # 最小 200 USDT
  --maxInvestment 600       # 最大 600 USDT
```

**动态逻辑**：
- 价格较上周下跌 >5%：投资额 × 1.5（600 USDT）
- 价格较上周上涨 >5%：投资额 × 0.5（200 USDT）
- 价格波动 <5%：正常投资 400 USDT

```
1. 改为每周一次（手续费 ≈ 0.65%）

```
