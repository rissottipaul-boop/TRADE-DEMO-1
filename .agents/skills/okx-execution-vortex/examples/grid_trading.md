```bash

  --instId BTC-USDT \
  --lowerPx 50000 \
  --upperPx 52000 \
  --gridNum 10 \
  --investment 3750 \
  --lever 1 \           # 现货杠杆为1
  --runType arithmetic \ # 等差网格
```

## 关键逻辑说明

1. **`--runType arithmetic`**：等差网格（固定价格间隔），另有等比网格
2. **`--triggerPx`**：触发价格，当前价在此价格时立即启动
3. **`--stopType profit`** 和 `--stopPxRatio 0.05`**：盈利5%后自动停止
4. **`--tpRatio 0.005`** 和 `--slRatio 0.01`**：每格止盈0.5%、止损1%
5. **资金分配**：自动计算现货持有和现金预留比例

## 高级功能：天地网格（无限网格）

用户可创建不设上限的网格：“天地网格 BTC，基准价 51000，上下各5%，每格0.5%”

```bash
okx bot grid create \
  --instId BTC-USDT \
  --gridType heaven_earth \  # 天地网格类型
  --basePx 51000 \          # 基准价格
  --gridRange 0.05 \        # 上下各5%
  --gridNum 20 \            # 总格数
  --investment 5000 \
  --lever 1
```

```
问题：过窄区间会导致频繁触发，手续费磨损严重
建议调整：上下各扩宽 1-2%
```
