## 7. Правила мониторинга (для MON-FLEET, Ops Sentinel)

**Команды:**
- гриды: `okx --demo bot grid details --algoOrdType grid --algoId <id>` — поля `state`, `totalPnl`, `gridProfit`, `floatProfit`, `pnlRatio`, `arbitrageNum`, `runPx`;
- DCA: `okx --demo bot dca details --algoOrdType spot_dca --algoId <id>` — `avgPx`, `upl`, `fillSafetyOrds`, `slPx`, `tpPx`, `curCycleId`; `okx --demo bot dca orders --algoOrdType spot_dca` — `totalPnl`, `pnlRatio`;
- цена: `okx --demo market ticker <inst>`.

Запросы разносить на ≥ 0.4 с (лимит tradingBot — 20 запросов за 2 с на UID).

**Стоп-условия для гридов.** Остановка — `okx --demo bot grid stop --algoOrdType grid --algoId <id> --instId <inst> --stopType 1`.

| Условие | Действие |
| --- | --- |
| Цена ≤ `slTriggerPx` | Автостоп биржей с продажей базы. Проверить `state` и записать PnL |
| Цена < `minPx` дольше **4 ч** (один бар 4H) | Стоп `--stopType 1`, не дожидаясь SL: гипотеза боковика не подтвердилась (grid-strategy-design §3) |
| Цена > `maxPx` дольше **12 ч** | Стоп `--stopType 1`: прибыль зафиксирована, капитал простаивает. Перезапуск диапазона — только отдельной записью с новым расчётом режима |
| `totalPnl` ≤ −6% инвестиции (ETH −108, SOL −90, SUI −72, ADA −66, TRX −48, ETC −48, APT −48) | Стоп `--stopType 1` |
| 4H-режим пары стал StrongDn, а цена в нижней трети диапазона | Стоп `--stopType 1`. StrongUp — только предупреждение: выход вверх безубыточен |

**Флот целиком:**
- Σ `totalPnl` флота ≤ **−1 200 USDT** (≈ расчётный худший случай 1 165.9 после FLEET-EXPAND; до него порог был −1 100) — SL отработали хуже модели. Остановить все 11 ботов (`--stopType 1`) и завести инцидент в `ops/incidents.md`. PnL OKB-BTC — в BTC, пересчитывать по текущему BTC-USDT.
- Бот вышел из `running` без нашего действия — инцидент и разбор причины (`bot grid orders --history` / `bot dca orders --history`).
- **Kill-switch останавливает grid и DCA** (FLEET-KILL-DCA, 24.09). `connector.emergency_stop` отменяет ордера, затем останавливает `grid`/`contract_grid` и `spot_dca`/`contract_dca`.
