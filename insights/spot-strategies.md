# Стратегии для старта на споте (и дальше)

- **Дата:** 2026-09-23
- **Тема:** Выбор первых торговых стратегий для полной автоматизации на OKX (спот → деривативы)
- **Статус:** idea (частично validated — источники указаны у каждого блока; контракт grid order-algo и поддержка tradingBot в демо подтверждены 2026-09-24)
- **Решение, которое принимается:** какие стратегии реализовывать первыми и в каком порядке; какие идеи из обзорных заметок 2026 применимы на практике, а какие — отложить

---

## 1. Кандидаты на старт (спот, OKX)

### 1.1 Grid (сеточная торговля) — кандидат №1 для MVP
- Принцип: сетка лимитных ордеров в ценовом коридоре, заработок на колебаниях внутри боковика без прогноза направления.
- **Ключевая находка:** у OKX есть **встроенный API торговых ботов** — можно не писать свою сетку на старте, а управлять биржевой:
  - `POST /api/v5/tradingBot/grid/order-algo` — создание (типы `grid` = спот-сетка, `contract_grid` = контрактная; параметры `maxPx`/`minPx` — границы диапазона)
  - `GET /api/v5/tradingBot/grid/ai-param` — **публичный** эндпоинт AI-подбора параметров сетки (бэктест от биржи)
  - `POST /api/v5/tradingBot/grid/min-investment` — расчёт минимальных инвестиций (публичный)
  - `POST /api/v5/tradingBot/grid/withdraw-income` — вывод прибыли спот-сетки
  - есть также публичный эндпоинт **RSI back-testing** в модуле grid
- Два пути: (а) своя реализация сетки — полный контроль и обучение, но больше кода и рисков исполнения; (б) биржевой grid-бот — быстрый старт, но логика «внутри» OKX, хуже для кастомных сигналов. Рекомендация: **сначала (б) для валидации идеи, параллельно строить (а)**.
- Риск: выход цены из диапазона → сетка «замораживается» с убыточной позицией. Нужны правила пересоздания/стопа всей сетки.

### 1.2 DCA (усреднение) — простейший робастный старт
- Регулярные покупки через равные интервалы или при просадке на N%. На споте без плеча риск ликвидации отсутствует.
- У OKX тоже есть DCA-бот в модуле tradingBot (упоминается в том же модуле API).
- Ценность как первого *собственного* кода: минимальная логика состояния, идеальный полигон для обкатки коннектора, ордеров, хранения состояния.

### 1.3 Mean-reversion (RSI/Bollinger) — первая сигнальная стратегия
- Классика Freqtrade sample: вход при пересечении RSI вверх через 30 + фильтры (объём > 0, TEMA vs BB), выход при RSI > 70 или по minimal_roi/stoploss.
- Важно: шаблонные стратегии Freqtrade **не прибыльны из коробки** — это каркас для обучения и бэктеста.
- Подходит как первая стратегия с реальной логикой входа/выхода на исторических данных.

### 1.4 Trend-following (EMA-кроссы, breakout) — вторая сигнальная
- Дополняет mean-reversion: работает в тренде, где MR сливает. Полезно иметь обе и переключать по режиму рынка (volatility/regime filter).

## 2. Что брать из заметок 2026 (трезвая оценка)

| Идея из заметок | Вердикт | Комментарий |
|---|---|---|
| Grid + COMBO (Grid+DCA на фьючах) | ✅ брать (фаза 2–3) | Реально существует у Bitsgap; механика понятна. На фьючах — только после риск-модуля |
| Walk-forward бэктестинг | ✅ брать сразу | Обязательная методология против curve-fitting; поддержать в собственном бэктестере |
| Только закрытые свечи (anti-repainting), lookahead/recursive-анализ | ✅ брать сразу | Практики из Freqtrade: сигналы на закрытии свечи, вход на открытии следующей; не использовать `.iloc[-1]`, `shift(-1)`, `.mean()` по всему ряду |
| Стоп-лосс + minimal ROI + trailing | ✅ брать сразу | Базовый риск-каркас любой стратегии |
| Информационные бары (Volume/Dollar/CUSUM) + Triple Barrier | 🟡 фаза 3 (ML-этап) | Методология из Lopez de Prado; имеет смысл при переходе к ML-разметке, не на старте |
| ML-фильтр сигналов (FreqAI-подобный слой) | 🟡 фаза 3 | Поверх стабильной сигнальной стратегии |
| LLM-сентимент (FinBERT/GPT) | 🟡 фаза 3–4, как фильтр | Заявленный Sharpe 3.05 — из одной статьи, **не верифицировано**, относить как низкую надёжность; дорого в реальном времени |
| DRL (PPO/A2C/DQN), адаптивный сайзинг | 🔴 фаза 4+, эксперимент | Высокий риск переобучения; только после накопления собственных данных и стабильной инфраструктуры |
| Ончейн-агенты (ElizaOS, Virtuals), TEE, DePIN | 🔴 вне скоупа | Это DEX/ончейн-экономика; наш проект — CEX (OKX). TEE как защита ключей — интересно, но избыточно на старте; достаточно IP-whitelist + ключ без withdraw |
| Коммерческие платформы (3Commas/Bitsgap/Pionex) | ℹ️ референсы | Не использовать, но изучать UX/механики как референс (COMBO, AI-генерация параметров сетки) |

## 3. Методология бэктестинга (обязательный минимум)

Из документации Freqtrade — применимо к любому бэктестеру:
1. **Anti-lookahead:** сигналы только на закрытых свечах; вход — на открытии следующей; запрет `shift(-1)`, абсолютных индексов, глобальных агрегатов; ресемплинг с `label='right'`; слияние таймфреймов через forward-fill без заглядывания.
2. **Startup period:** закладывать прогрев индикаторов (напр. EMA100 → ≥400 свечей запаса).
3. **Комиссии и проскальзывание** в тесте; на OKX учитывать правило 1000 мейкеров для крупных маркет-ордеров.
4. **Walk-forward:** оптимизация на скользящем окне, проверка на «невидимых» данных.
5. Валидационные прогоны: аналоги `lookahead-analysis` и `recursive-analysis` в своём бэктестере.
6. Dry-run (paper) минимум 7–14 дней перед демо-деньгами; демо OKX — перед боем.

   - Общие: `instId`, `algoOrdType` (`grid`/`contract_grid`), `maxPx`/`minPx`, `gridNum`, `runType` (1 арифм. / 2 геом.), `algoClOrdId`, `tag`.
   - **Стоп/тейк всей сетки:** `tpTriggerPx` / `slTriggerPx` — верхнеуровневые параметры.
   - **Триггерные условия:** массив `triggerParams[]` с `triggerAction` = `start`/`stop`; `triggerStrategy` = `instant`/`price`/`rsi`; для rsi — `timeframe` (3m–1D), `thold` (1–100), `triggerCond` (`cross_up`/`cross_down`/`above`/`below`/`cross`), `timePeriod` (14); для price — `triggerPx`; опционально `delaySeconds`.
   - **Поведение при остановке:** `stopType` внутри triggerParams с action=stop: спот-сетка `1` = продать базовую валюту, `2` = оставить; контрактная `1` = закрыть все позиции по рынку, `2` = оставить.
   - Спот: `quoteSz` или `baseSz` (одно из двух обязательно), `tradeQuoteCcy`. Контракт: `sz` (маржа USDT), `direction` (long/short/neutral), `lever`, `basePos`, `tpRatio`/`slRatio`.
