# Дизайн trend-following (EMA/ADX) стратегии с ADX-режимом (Фаза 2, задача TREND-DESIGN)

- **Дата:** 2026-10-03
- **Тема:** Спецификация запасной сигнальной стратегии — trend-following на EMA(20)/EMA(50)/EMA(200) с режимным фильтром ADX(14), ATR(14)-трейлингом для BTC-USDT спот и SWAP, 1H; anti-lookahead совместимость с бэктестером, ожидаемые метрики
- **Статус:** готово к реализации в бэктестере
- **Задача:** TREND-DESIGN
- **Решение, которое принимается:** точные параметры индикаторов, правило входа/выхода, стоп/трейлинг, minimal ROI и пороговые ожидания по метрикам для запасной сигнальной стратегии (дополнение к mean-reversion: работает в тренде, где MR сливает)

> Это инженерная спецификация, а не финансовый совет. Численные пороги — стартовые дефолты для demo/paper, подлежат калибровке (план калибровки — §7, реализация в `src/backtest/`). Статистическая точность внешних бэктестов ≠ гарантия прибыльности на наших данных (roadmap, Фаза 2 п.5).

## 1. Инструмент, таймфрейм и обоснование выбора

Стратегия торгует **BTC-USDT спот и SWAP, 1H бары** — тот же датасет и глубина истории (≥ 2 года), что уже утверждены дизайном бэктестера [И1] и картой стратегий [И6].

Выбор 1H, а не 5m/15m:

1. Это рабочий таймфрейм сигнальных стратегий Фазы 2 ([И1] §4.4) — паритет данных с mean-reversion ([meanrev-strategy-design.md](meanrev-strategy-design.md) §1) и прямой reuse walk-forward окон 180/30/30.
2. Трендовые входы редки и чувствительны к шуму: на 1H доля комиссий (тейкер 0.10%×2 = 0.20% на круг, [И1] §3.1) против типичного трендового движения в разы меньше, чем на 5m ([И6] §1.4 — trend работает там, где MR сливает, но только при достаточном размахе хода).
3. 1H — компромисс между запаздыванием EMA/ADX (на 4H/D лаг съедает половину тренда BTC) и шумом младших ТФ; 15m остаётся доступен как detail-таймфрейм бэктестера для уточнения исполнения стопа внутри бара ([И1] §4.4).
4. Спот-ветка — **long-only** (спот без плеча, risk-core §2.1); short-ветка — только **SWAP** (Фаза 5+, деривативы), с плечом строго ≤ 3x isolated (см. §6).

## 2. Индикаторы и параметры

### 2.1 Тренд: EMA(20) / EMA(50) + EMA(200)

- **EMA(20)** — быстрая нога кросса (захват начала импульса).
- **EMA(50)** — медленная нога кросса (подтверждение смены среднесрочного направления).
- **EMA(200)** — базовый фильтр общего направления: long разрешён только выше EMA(200), short (SWAP) — только ниже.
- Обоснование: EMA-кроссы — канонический каркас трендовых шаблонов Freqtrade (быстрый/медленный кросс + старший фильтр в `populate_entry_trend`) [И2]; длинная EMA(200) как фильтр бычьего/медвежьего режима — стандарт практиков, снижающий контртрендовые входы [И5]. Все три EMA — стандартные оконные функции, совместимы с запретом глобальных агрегатов ([И1] §1.1 п.4).

### 2.2 Режимный фильтр: ADX(14) со сглаживанием Уайлдера (+DI / −DI)

- Индикатор **ADX(14)** по оригинальной формуле J. Welles Wilder Jr. (сглаживание Уайлдера для +DM/−DM, +DI/−DI, DX→ADX) [И3].
- Пороги — из [spot-strategies.md](spot-strategies.md) §4 п.4 (стартовый критерий переключения MR ↔ trend, уже принятый в проекте):
  - **ADX > 25 = тренд** — трендовые входы разрешены;
  - **ADX < 20 = боковик** — трендовые входы запрещены (режим mean-reversion/grid);
  - **20–25 = зона неопределённости** — новых входов нет (или уменьшенный размер — на калибровку, дефолт: нет входа).
- Направленность: **+DI > −DI** подтверждает восходящий тренд (условие long), **−DI > +DI** — нисходящий (условие short). Сам ADX направления не имеет — только сила тренда [И4].
- Обоснование: ADX входит в стандартный набор индикаторов шаблонных стратегий Freqtrade (`ta.ADX`) [И2]; пороги 20/25 — правило Уайлдера, автора индикатора [И4]. Ограничение (фиксируем честно): ADX **лаговый** и даёт ложные пересечения в рваном рынке — поэтому комбинируется с ценовым фильтром (EMA-кросс + положение относительно EMA(200)), а не используется сольно [И4].

### 2.3 Волатильность и стоп: ATR(14)

- **ATR(14)** (Уайлдер) — мера текущей волатильности для динамического трейлинг-стопа (§4.1).
- Обоснование: ATR-стоп 1.5–2.0× — консенсус практиков для трендовых/свинговых подходов ([meanrev-strategy-design.md](meanrev-strategy-design.md) §5, [И5]); для тренда берём **широкую** границу диапазона — **2.0×ATR(14)**, чтобы не выбивать позицию рыночным шумом (узкие 1.5× — для короткого MR-удержания, здесь удержание длиннее по тезису).

### 2.4 Прогрев (warm-up), совместимость с anti-lookahead-контрактом бэктестера

- Доминирующее окно — **EMA(200)**: по формуле бэктестера `warmup = max_window × 2` ([И1] §1.1 п.3) формальный минимум = **400 баров**. ADX(14)/ATR(14)/EMA(50) требуют меньше (сходимость Уайлдера — 3–5×период ≈ 42–70 баров).
- **Решение: warmup = 400 подтверждённых 1H-баров** (≈ 17 дней — пренебрежимо мало против требуемых ≥ 2 лет истории, [И1] §4.4).
- Это НЕ требует изменений anti-lookahead контракта: warmup — частный случай правила [И1] §1.1 п.3, стратегия передаёт значение через `startup_candle_count`-подобный параметр движка; **NaN-guard** ([И1] §1.2): сделка невозможна на баре, где любой из EMA(20/50/200), ADX, +DI/−DI, ATR = NaN.
- Исполнение: сигнал на подтверждённой свече `t` (**confirm=1**), исполнение по **open(t+1)** — без изменений модели исполнения ([И1] §1.1 п.2).

## 3. Правила входа (entry)

Вход на подтверждённой свече `t` (флаг OKX `confirm=1`), исполнение — на **open(t+1)**; дополнительно `volume(t) > 0` (защита от «мёртвых» баров, [И1] §4.1).

### 3.1 Спот (long-only)

```
entry_long(t) =
      EMA20(t) > EMA50(t)               # быстрый кросс вверх
  AND close(t) > EMA200(t)              # базовый фильтр общего направления
  AND ADX14(t) > 25                     # режим — тренд
  AND plus_DI(t) > minus_DI(t)          # направление тренда — вверх
  AND volume(t) > 0
```

### 3.2 SWAP (long и short)

Long — те же условия, что §3.1. Short — зеркально:

```
entry_short(t) =
      EMA20(t) < EMA50(t)               # быстрый кросс вниз
  AND close(t) < EMA200(t)              # цена под длинным фильтром
  AND ADX14(t) > 25                     # режим — тренд
  AND minus_DI(t) > plus_DI(t)          # направление тренда — вниз
  AND volume(t) > 0
```

Зона ADX 20–25 — **без новых входов** в обе стороны (дефолт; смягчение до уменьшенного размера — вопрос калибровки §7, не дефолт).

Обоснование формы правила: кросс EMA задаёт момент, EMA(200) отсекает контртренд, ADX отсекает боковик (где EMA-кроссы дают серию ложных пил — задокументированная слабость «голых» кроссов, [И5]); связка «кросс + ADX-фильтр» — стандартная форма трендовых шаблонов Freqtrade [И2]. Порт стратегии во Freqtrade для перекрёстной проверки ([И1] §5 п.4) — прямой 1:1.

## 4. Правила выхода и стоп-лосс

Порядок проверки на баре (детерминированный): **1) стоп/трейлинг → 2) minimal ROI → 3) индикаторный выход** — стоп приоритетнее (тот же принцип «консервативный сценарий», [И1] §1.1 п.7; зеркально [meanrev-strategy-design.md](meanrev-strategy-design.md) §6.3).

### 4.1 Стоп-лосс и трейлинг: Chandelier Exit / ATR-трейлинг

```
# long:
trail_long(t) = max( trail_long(t-1), highest_high(N, t) − 2.0 × ATR14(t) )
# short (SWAP):
trail_short(t) = min( trail_short(t-1), lowest_low(N, t) + 2.0 × ATR14(t) )
```

- Множитель **2.0 × ATR(14)** (дефолт; калибруется в диапазоне 1.5–3.0 — §7).
- Якорь экстремума: дефолт **N = 22 бара** (≈ сутки на 1H; калибруется); Chandelier Exit в классике — ATR от экстремума за окно [И5].
- Трейлинг **только подтягивается** вслед за ценой, никогда не расширяется против позиции; начальное значение на баре входа = entry ∓ 2.0×ATR(14).
- Исполнение стопа внутри бара — по консервативному правилу «low раньше high» плюс проскальзывание ([И1] §1.1 п.7, §3.3): `exec_stop = stop_price × (1 ∓ slippage_bps/1e4)`, slippage_bps = 5 (дефолт бэктестера; стресс ×2 обязателен).

### 4.2 Выход по индикаторам (затухание тренда)

```
exit_long(t)  = crossed_below(EMA20(t), EMA50(t))   # обратный кросс
             OR ADX14(t) < 20                        # тренд затух — режим боковика
exit_short(t) = crossed_above(EMA20(t), EMA50(t))
             OR ADX14(t) < 20
```

Зона 20–25 при открытой позиции — **удержание** (не выход): выходим только при подтверждённом спаде ниже 20, чтобы не рубить позицию на шуме границы.

### 4.3 Minimal ROI / фиксация прибыли по времени

ROI-таблица — функция «время в сделке → минимальная доходность для принудительного выхода», механика Freqtrade ([meanrev-strategy-design.md](meanrev-strategy-design.md) §6.1, [И2]). Тренд держится дольше MR, поэтому горизонты длиннее, пороги ниже:

| Минут в сделке | Требуемая доходность |
| --- | --- |
| 0 | **4.0%** |
| 720 (12ч) | **2.5%** |
| 2880 (48ч) | **1.0%** |
| 7200 (120ч / 5 сут) | **0.0%** — принудительный выход по безубытку (тайм-стоп) |

Числа стартовые, калибруются (§7). Anti-lookahead не нарушается: правило использует только время с открытия и исторические цены тем же open(t+1)-исполнением ([И1] §1.1).

## 5. Интеграция с риск-ядром (`src/risk.py`)

Совместимость без ослабления лимитов (контракт [risk-core.md](risk-core.md) §2, §6):

- **`check_entry_allowed(inst_id, side)`** (`src/risk.py:264`, обёртка `:730`) вызывается перед каждым входом без исключений — kill-switch/breaker/блокировка инструмента/лимит сделок в день имеют приоритет над сигналом стратегии.
- **`size_position(equity, entry, stop, ...)`** (`src/risk.py:295`, обёртка `:741`): дистанция `|entry − stop|` = текущее значение ATR-трейлинга на баре входа (2.0×ATR(14)); **риск на сделку 1% equity, жёсткий потолок 2%** — без изменений.
- **Потолок позиции 15% equity (notional cap)** — без изменений: если ATR-дистанция настолько мала, что размер превышает кап — вход **отклоняется** (warnings от `size_position()`), стратегия кап не переопределяет.
- **Drawdown breaker и лимит потерь**: глобальный breaker −15%, дневной −6%, системная пауза после серии — наследуются из риск-ядра без исключений; бэктест-MDD ≤ 10% ([И1] §6.2 п.4) оставляет буфер ×1.5 до breaker'а.
- SWAP-ветка дополнительно обязана пройти проверки плеча/маржи риск-ядра (плечо ≤ 3x — §6).

## 6. Пригодность для Copy Trading и SWAP деривативов

Оценка использования в качестве **ведущей стратегии** в OKX Copy Trading / Signal Bot [И7]:

1. **Чувствительность к задержке сигналов — низкая (плюс для копирования).** Сигнал живет на 1H-свечах: исполнение на open(t+1) даёт подписчикам окно ~до часа на репликацию; дрейф цены копирования против ведущей за это окно на порядки меньше типичного трендового хода (единицы × ATR против цели ≥ 2×ATR). Для сравнения: MR-стратегия на том же ТФ более чувствительна к проскальзыванию входа (разворотные точки острее).
2. **Плечо строго ≤ 3x isolated.** Тренд-стратегия переживает глубокие откаты внутри тренда; высокое плечо превращает штатный откат в ликвидацию. 3x на BTC (≈ −33% до ликвидации без учёта MMR) даёт запас, покрывающий ATR-стоп 2.0×ATR в разы; cross-маржа запрещена (изоляция убытка позицией).
3. **Ставка финансирования (funding rate).** SWAP-позиции в тренде держатся сутками (§4.3 — до 5 суток): при сильном консенсусе funding съедает часть трендовой прибыли (лонг платит в бычьем перекосе). Учёт: (а) логировать funding в PnL бэктестера SWAP-ветки (источник данных — архив funding, в проекте `src/funding_archive.py` / [funding-carry.md](funding-carry.md)); (б) опциональный guard «не входить в long при экстремально положительном funding» — вопрос калибровки, не дефолт v1.
4. **Запас до ликвидации.** При 3x isolated и стопе 2.0×ATR(14) принудительная ликвидация недостижима раньше стопа в штатных условиях (дневной ATR BTC ≪ 33%/3x-буфера); гэп-риск покрывается консервативным исполнением стопа `min(open, stop)` (отклонение BT-IMPL [И1] §0.1 п.1).
5. **Поведение для подписчиков:** низкий win rate (35–45%, §7) при редких крупных выигрышах — психологически тяжёлый профиль для копирования (длинные серии убытков ≤ 7 — в пределах гейта [И1] §6.2 п.8); в карточке Signal Bot честно указывать ожидаемый win rate и max серию убытков, иначе отток подписчиков на первой просадке.

## 7. Калибровка и ожидания в бэктестере

### 7.1 Сравнение с mean-reversion (зеркальный профиль)

| Метрика | Mean-reversion (RSI/BB) — внешние ориентиры | Trend (EMA/ADX) — внешние ориентиры |
| --- | --- | --- |
| Win rate | высокий, **55–71%** | низкий, **35–45%** |
| Profit factor | ~1.0 без фильтров | **> 1.5** (цель; дефолт-приёмка ≥ 1.3 по [И1] §6.2) |
| Payoff ratio (avg win / avg loss) | < 1 (мелкие победы / крупные поражения) | **> 2.0** — редкие крупные тренды перекрывают частые мелкие стопы |
| Роль ADX | MR сливает в тренде (фильтр ADX < 20 — её режим) | ADX > 25 отсекает ложные EMA-кроссы в боковике — зеркальный фильтр |

Тезис: стратегии — **режимная пара**: MR работает в боковике (ADX < 20), trend — в тренде (ADX > 25); переключатель — уже принятый критерий [spot-strategies.md](spot-strategies.md) §4 п.4.

### 7.2 План калибровки в `src/backtest/`

1. Реализация стратегии как модуля `src/backtest/trend.py` (по образцу `src/backtest/meanrev.py`): `populate_indicators` (EMA 20/50/200, ADX/+DI/−DI 14, ATR 14) + `populate_entry/exit` по §3–§4; warmup=400.
2. Параметрическая сетка (walk-forward 180/30/30, [И1] §2): ADX-порог входа {22, 25, 28}, ADX-порог выхода {18, 20}, ATR-множитель {1.5, 2.0, 2.5, 3.0}, окно Chandelier N {14, 22, 30}, ROI-таблица {2 варианта §4.3 ± сдвиг}.
3. Приёмка — гейт [И1] §6.2 целиком (expectancy > 0 при slip×2, PF ≥ 1.3, Sharpe OOS ≥ 0.5, MDD ≤ 10%, ≥ 100 сделок, ≥ 60% прибыльных окон, издержки < 50%, серия ≤ 7).
4. Перекрёстная сверка с Freqtrade на одном датасете ([И1] §5 п.4) — расхождение сделок = баг.
5. SWAP-ветка калибруется отдельно (funding в издержках); спот-ветка — без funding.
