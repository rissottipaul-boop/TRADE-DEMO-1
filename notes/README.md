# Заметки человека

Сюда Obsidian кладёт новые заметки (настройка в `.obsidian/app.json`). Пишите что угодно: идеи, наблюдения за рынком, решения, черновики задач.

- Агенты читают эти заметки как контекст. Править их или брать отсюда поручения агенты не будут. Чтобы агент взялся за работу, добавьте строку на [доску](../ops/board.md) по шаблону `board-task` (см. [пульт](../obsidian/dashboard.md)).
- Папка входит в репозиторий: заметки попадают в git вместе с проектом. Ключи, пароли и seed-фразы здесь не храните.
- Ссылку на документ проекта вставляйте через `[[`: Obsidian предложит файл и сам запишет ссылку в формате markdown.
