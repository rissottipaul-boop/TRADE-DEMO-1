# Obsidian в проекте

Vault — корень репозитория `C:\TG\BOT\TRADE DEMO 1`. Obsidian здесь — пульт и записная книжка человека. Работу по-прежнему ведут агенты через доску [ops/board.md](../ops/board.md) по [регламенту](../AGENTS.md).

## Пульт

[Home.md](../Home.md) открывается при запуске (Alt+H). Он ничего не меняет, только читает файлы проекта:

- **плашки безопасности** — флаги `data/KILL` и `data/STOP_ENGINE`, свежесть `logs/engine.log` (движок пишет раз в минуту; тишина дольше 3 минут — вероятно, остановлен), live-окно из `ops/live-policy.json`;
- **доска по статусам** — разбор тот же, что у автопилота: «можно брать» = `ready` или наступивший `scheduled`, у которого закрыты все зависимости;
- **последние инциденты** и **инсайты** по времени правки.

Пульт обновляется, когда меняется любая заметка. Принудительно — Alt+R. Точные цифры риска и движка — только командой `python -m src.ops status`.

## Как ответить агентам

1. На пульте в разделе «Ждёт решения человека» нажми **Ответить** у задачи.
2. Откроется `notes/decisions/<ID>.md` с вопросом с доски. Впиши решение и причину.
3. Оркестратор при следующем SYNC перенесёт решение на доску и поставит в файле `status: перенесено`. До этого ответ виден на пульте в «Мои ответы, ещё не на доске».

Что агенты не сделают даже по записанному решению: включение live, сброс kill-switch, ослабление лимитов, секреты. Это человек делает сам (AGENTS.md §2), и guard не пропустит агента.

## Дневник и шаблоны

| Клавиши | Что |
| --- | --- |
| Alt+H | Пульт |
| Alt+D | Дневник на сегодня — `notes/daily/ГГГГ-ММ-ДД.md`: флаги, вопросы ко мне, заметки, личные задачи |
| Alt+T | Вставить шаблон из `notes/templates/` |
| Alt+R | Обновить вьюхи Dataview |

Шаблоны:

- **Задача доски** — строка для таблицы «Активные» в `ops/board.md`: поставь курсор на пустую строку сразу под последней строкой таблицы и вставь. Заголовки колонок не трогай — автопилот читает таблицу машинно.
- **Инсайт** — каркас в формате исследователя. Файл клади в `insights/`.
- **Заметка** — свободная заметка в `notes/`.

Личные задачи — чекбоксы с тегом `#задача`. Плагин Tasks видит только их: чек-листы в `insights/` задачами не считаются.

## Правила vault

- **Ссылки — обычный markdown с относительным путём** (`[доска](../ops/board.md)`), не `[[вики-ссылки]]`. Так их понимают VS Code, GitHub и агенты. Obsidian так и настроен — не переключай.
- `notes/` — твоё. `insights/`, `ops/`, `src/` пишут агенты. Править их руками можно, но доску — только точечно.
- `src/`, `tests/`, `data/`, `logs/` исключены из поиска и графа. В проводнике они остаются.
- `.env` и другие файлы с точкой Obsidian не показывает и не индексирует.

## Git-плагин

Репозиторий общий с агентами, они коммитят принятые задачи сами. Поэтому:

- автокоммит, автопуш и автопул выключены, pull при запуске тоже;
- слияние — `merge` без стратегии `ours` (с `rebase` + `ours` конфликт молча выбрасывал бы чужие изменения);
- коммить из Obsidian **только свои заметки**: стейджи `notes/` в панели Source Control, а не «Commit all». Иначе незаконченный код агента уйдёт в коммит «Заметки Obsidian».

## Внимание: Smart Chat

Smart Connections считает связи между заметками локально. **Smart Chat** настроен на OpenRouter — текст заметок, которые ты даёшь ему в контекст, уходит внешнему сервису. Ключи, пароли и вывод `.env` в заметки не вставляй.

## Что не используем

- **Kanban** для задач агентов: вторая доска разойдётся с `ops/board.md`. Для личных списков — можно.
- **Templater**: шаблоны написаны на синтаксисе встроенных «Шаблонов» (`{{date}}`), вставка — Alt+T.
- **Minimal Theme Settings** работает только с темой Minimal, а сейчас стоит Adrenaline.
