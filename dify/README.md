# Dify AI DSL — Экспорт и запуск всего проекта в Cloud Dify AI

В этом каталоге подготовлены готовые DSL-файлы для развёртывания всей мульти-агентной системы торговли OKX в **[Cloud Dify AI](https://cloud.dify.ai)** или локальном Dify:

1. **`dify/okx_multi_agent_system.yml`** — **Chatflow (Advanced-Chat)**:
   - Полный визуальный граф маршрутизации запросов по 6 специализированным ролям:
     - 🎯 `Project Orchestrator` (доска задач, фазы)
     - 🔍 `Crypto Insight Hunter` (исследования стратегий)
     - ⚡ `Insight Executor` (код, тесты, бэктесты)
     - 💰 `OKX Trader` (ордера, нативные grid/DCA боты)
     - 🚀 `Pump Risk Taker` (памп-карман, PUMP-STALE)
     - 🛡️ `Ops Sentinel` (мониторинг движка, эквити, breakers)
   - Встроенный узел **`Risk Guard` (Python Code Node)**: автоматическая фильтрация недопустимых операций (блокировка вывода средств, запрет самовольного включения live, контроль плеча <= 3x по AGENTS.md §2).
   - Интеграция с облачной базой **CockroachDB Cloud (`legion-pi`)** и **OKX API**.

2. **`dify/okx_agent_assistant.yml`** — **Agent-Chat (Autonomous Agent)**:
   - Автономный агент на архитектуре ReAct / Function Calling с динамическим переключением ролей и памятью диалога.

## 🚀 Пошаговая инструкция по импорту в Cloud Dify AI

### Шаг 1. Откройте Dify
1. Перейдите на сайт **[https://cloud.dify.ai](https://cloud.dify.ai)** (или ваш собственный сервер Dify).
2. Войдите в свой аккаунт (через Google, GitHub или Email).

### Шаг 2. Импортируйте DSL файл
1. В верхнем меню выберите раздел **Studio** (Студия) -> **Create from DSL** (Создать из DSL) / **Import DSL file**.
2. Нажмите кнопку выбора файла и укажите:
   - `c:\TG\BOT\TRADE DEMO 1\dify\okx_multi_agent_system.yml` (рекомендуется — полный мульти-агентный чатфлоу).
3. Нажмите **Create** (Создать).
4. Dify автоматически развернёт визуальный граф со всеми агентами, промптами, правилами риска и маршрутизатором!

### Шаг 3. Подключение моделей (Model Providers)
1. В настройках Dify перейдите в **Settings** (Настройки) -> **Model Provider**.
2. Убедитесь, что у вас подключен один из провайдеров:
   - **OpenAI** (GPT-4o, GPT-4o-mini)
   - **Anthropic** (Claude 3.5 Sonnet / Opus)
   - **DeepSeek** (DeepSeek-V3 / R1)
   - **Google Gemini** (Gemini 1.5 Pro / Flash)
*(Вы можете в один клик переключить модель любого узла в графе)*.

### Шаг 4. Публикация и запуск
1. В правом верхнем углу нажмите синюю кнопку **Publish** (Опубликовать) -> **Update**.
2. Нажмите **Run App** (Запустить приложение).
3. Теперь весь проект OKX-бота доступен вам через веб-интерфейс Dify, мобильный браузер, а также через API Dify для внешних интеграций!

## 🛡️ Безопасность и соответствие регламенту

- В Dify перенесены все системные промпты из `.github/agents/*.agent.md`.
- Узел **Risk Guard** на уровне Python-кода блокирует любые попытки вывода средств (Withdraw) и превышения лимитов риска.
- Ваши ключи API остаются защищёнными в переменных окружения.
