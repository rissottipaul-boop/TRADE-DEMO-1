# Экономия контекста агентов

Дата: 2026-09-30. Статус: меры 1–5 внедрены, 6–7 частично, 8 — только замер байтов. Задача доски — AGENT-TOKEN-ECONOMY.

Короткие правила — [AGENTS.md](../AGENTS.md) §3, назначения моделей — [agent-team.md](agent-team.md). Этот файл объясняет, что и почему экономим и где граница.

## Главное правило

Экономим объём **прочитанного**, а не качество **сделанного**. Ради экономии не снижают: назначенную модель и reasoning, объём тестов и проверок, риск-лимиты, частоту мониторинга и сверку с биржей. Сводка — указатель на источник, а не его замена: при сомнении, ошибке или неоднозначности читают исходник.

Obsidian — общая долговременная память в Markdown: одни и те же файлы доступны всем агентам. Экономию даёт выборочное чтение этих файлов вместо пересказа истории в промпте. Сам vault не уменьшает токенизацию и не создаёт общий кэш промптов между моделями.

## Особенности клиентов

- **Codex / OpenAI.** Одинаковое начало запроса помогает кэшу; cached input дешевле, но остаётся контекстом. Цена API и расход подписки — разные величины. [Prompt caching](https://developers.openai.com/api/docs/guides/prompt-caching).
- **Claude Code.** Кэш и auto-compaction встроены; `/context` — состав контекста, `/usage` — расход, `/compact <что сохранить>` — сжатие с инструкцией. Для несвязанной задачи новая сессия лучше бесконечного диалога. [Costs](https://code.claude.com/docs/en/costs).
- **Gemini CLI.** Token caching документирован для API key / Vertex; для OAuth Code Assist не заявлен. `/stats` — токены и кэш. [Token caching](https://geminicli.com/docs/cli/token-caching/).
- **Antigravity.** Правила `always_on` / `glob` / `manual` / `model_decision` позволяют грузить узкие инструкции по задаче; сверять с установленной версией, настройки Gemini CLI не переносить вслепую. [Rules](https://antigravity.google/docs/rules/).
- **Muse.** `/compact` — сжатие с потерями, `/recap` только показывает сводку и контекст не уменьшает. Опоры для обещаний по кэшу Muse нет. [Working with the agent](https://dev.meta.ai/docs/muse-code/interactive).

## Что не делать

- Не отвечать по сводке, если задача торговая или ops: состояние счёта и движка — только штатными командами заново.
- Не читать доску выборочно, когда `agent_context` сообщил о дубликате ID или ошибке разбора.
- Не заменять полный прогон `unittest discover` частичным ради экономии перед `done`.
- Не выбирать модель дешевле назначенной без явного решения в [agent-team.md](agent-team.md).
