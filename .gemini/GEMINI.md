# Правила для Antigravity / Gemini CLI в проекте OKX-бота

Этот файл — **зеркало** `AGENTS.md` для агентов, работающих через Antigravity / Gemini CLI.
Полный регламент — в [AGENTS.md](../AGENTS.md). Здесь — ключевые правила, чтобы агент
не нарушил периметр безопасности при автономной работе.

## Язык

Отвечай, пиши комментарии и документы по-русски.

## Источники правды

1. `AGENTS.md` — полный регламент: роли, автономия (§2), цикл работы (§3), доска (§4), карта кода (§6).
2. `ops/board.md` — текущие задачи.
3. `.github/agents/*.agent.md` — описания ролей.

Прочитай `AGENTS.md` целиком перед началом работы.

## Критические запреты (AGENTS.md §2, правая колонка)

- **Вывод средств** — НИКОГДА.
- **Секреты**: `.env`, ключи, токены, профили `okx` CLI — НЕ ЧИТАТЬ, НЕ МЕНЯТЬ.
- **Guard-хук** (`ops/hooks/`, `.github/hooks/`), `.claude/settings.json`, `ops/autopilot.json` — НЕ МЕНЯТЬ.
- **Kill-switch и breaker** — НЕ СБРАСЫВАТЬ.
- **Live-торговля** — включение только человеком.
- **Ослабление лимитов** (`src/risk.py`, `pump-pocket.json`) — только человеком.
- **Удаление данных и баз состояния** — только человеком.

В сторону безопасности (остановка, ужесточение) — действуй сам.

## Карта кода

См. AGENTS.md §6. Ключевые команды:

```
# Тесты
.venv\Scripts\python.exe -m unittest discover -s tests -t .

# Статус
python -m src.ops status

# Движок
ops\engine.ps1 start / status / stop
```

## Цикл работы

SYNC → CLAIM → DO → VERIFY → RECORD → NEXT (AGENTS.md §3).

## Метка владельца ордера

Каждый ордер получает clOrdId с префиксом владельца через:
```
.venv\Scripts\python.exe -m src.order_owner new <код>
```

Сделано · Проверено · Доска · Нужно решение человека (AGENTS.md §8).
